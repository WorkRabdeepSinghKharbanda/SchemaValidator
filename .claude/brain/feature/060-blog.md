# Blog

- **Category:** Platform
- **Entry point:** `blog/index.html`, 16 posts at `blog/{slug}/index.html`, auto-discovered by `vite.config.ts` and `scripts/generate-sitemap.mjs`
- Static, no-React blog (same pattern as the SEO landing pages) with `BlogPosting` + `BreadcrumbList` JSON-LD per post, mostly 1200-1600 words each, tied to a real shipped feature or a general JSON Schema concept; `blog/index.html` is the only listing page, so a new post must be linked there to be discoverable by visitors. Every post has a hand-curated "Related posts" section — add a new post to a few existing posts' related lists too, not just the index. `blog/what-is-json-schema/` is a ~4000-word pillar post (a from-scratch beginner's guide, deliberately longer and more comprehensive than the rest) with an illustration (`public/blog-images/`, third-party MIT-licensed, tracked in `LICENSES.md`); every other post links to it via a `.beginner-note` line after the lede, for readers who find the other posts too advanced.
