# Tool Hubs and Breadcrumbs

- **Category:** Platform
- **Entry point:** `tools/index.html`, `tools/format-validators/index.html`, `tools/schema-tools/index.html`, `.breadcrumb` nav + `BreadcrumbList` JSON-LD on every static page
- Two category hubs (`ItemList` JSON-LD) group the 16 landing pages; every landing page, blog post, and hub page carries a breadcrumb back up the hierarchy — the actual hub-and-spoke navigation, not the page footers. A new landing page must be added to its hub's list and given a breadcrumb or it's an orphan.
