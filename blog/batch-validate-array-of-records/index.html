Batch-validating an array of records against one schema

Validating one record proves your schema works. Validating a thousand imported records proves your data does.

Why single-record validation isn't enough

A schema that correctly validates one hand-picked example doesn't tell you anything about the other 999 records in a real import. Bad data tends to cluster in edge cases — a null where a string was expected, a stray currency symbol, a date in the wrong format — that a single manually-checked example won't surface.

What a per-record result actually needs to show

An aggregate "12 of 1,000 failed" is a start, but not actionable on its own — you need to know exactly which 12, and why each one failed, without re-running validation on each one individually.

Export just what's broken

Once you can see which records failed, the next useful step is pulling just those out — for a fix pass, a bug report, or re-import after correction — rather than exporting the whole batch again and filtering by hand.

Try it

Schema Validator's batch mode does exactly this — a per-record pass/fail table, a progress bar for large batches, and an "export failing only" button — for JSON, YAML, or CSV arrays alike.
