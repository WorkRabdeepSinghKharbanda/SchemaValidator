Auto-generate sample test data from a JSON Schema

A hand-written test fixture can silently drift out of sync with the schema it's supposed to satisfy. Generated fixtures can't.

The problem with hand-written fixtures

A test fixture is usually written once and rarely revisited — but the schema it's meant to satisfy keeps changing. A new required field, a narrowed enum, or a stricter pattern can leave an old fixture technically invalid without anyone noticing, because nothing re-checks it against the current schema unless a test actually runs validation.

Generate instead of maintain

Generating sample data directly from the current schema sidesteps the whole problem — the sample is guaranteed to satisfy whatever the schema says right now, because it's built from the schema itself, not remembered from whenever the fixture was first written.

Bulk fixtures for batch tests

Need more than one record — say, seeding a test database or stress-testing a batch import? Generate many at once (up to 500 in one run) rather than looping a single-record generator by hand.
