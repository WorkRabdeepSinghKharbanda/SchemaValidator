Turn a JSON Schema into a TypeScript interface in seconds

Keeping a hand-written TypeScript type in sync with a JSON Schema by hand is exactly the kind of thing that should be automated.

Why this drifts in the first place

A JSON Schema validates data at runtime; a TypeScript interface types it at compile time. They describe the same shape, written twice, by hand, usually by two different people at two different times — which is exactly how they drift apart. A schema update that isn't mirrored into the type leaves TypeScript confidently wrong about what a value actually contains.

What a best-effort generator handles well

The common cases — type, properties, required, array items, enum, and oneOf/anyOf as unions — map cleanly to TypeScript. Nested objects become their own named interfaces automatically, so a deeply nested schema doesn't produce one giant inline type.

What still needs a human

Conditional schemas (if/then/else), allOf composition, and tuple-style items don't map onto TypeScript cleanly enough to auto-generate correctly — these fall back to unknown, which is a signal to review that part of the type by hand, not a bug.
