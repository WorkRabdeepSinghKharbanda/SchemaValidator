Generate a schema now

Why generate a schema instead of writing one by hand?

Writing a JSON Schema from scratch for an existing API response or config file means re-typing every field, type, and nesting level you can already see in the data. Schema inference reads your actual sample data and produces a starting schema in seconds, that you refine rather than write from zero.

How it works

  1. Open Schema Validator and paste sample JSON data into the data pane.
  2. Use the schema pane's "⋯" menu → "Infer schema from data".
  3. A draft schema is written into the schema pane, matching the data's types and nesting.
  4. Refine it — add required fields, tighten an enum, or switch to the Visual builder.

Frequently asked questions

Does it infer nested objects and arrays?

Yes, for object nesting. Arrays infer their shape from the first element only — a documented limitation, not a bug — so review array item schemas if your array has mixed shapes.

Is my sample data uploaded anywhere?

No — inference runs entirely in your browser.

Can I edit the generated schema afterward?

Yes, it's a normal editable schema in the schema pane — refine it in Code mode or the Visual builder like any other schema.

Does this generate a UI form from my schema?

No — this goes the other direction, inferring a schema from data. It doesn't render an input form from a schema.

Can I pick which JSON Schema draft the output targets?

Yes — the draft dropdown (draft-07, 2019-09, 2020-12) applies to the whole app, including inferred schemas.
