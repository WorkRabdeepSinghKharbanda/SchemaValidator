Why validate TOML against a JSON Schema?

TOML is the config format behind Cargo, Poetry, and plenty of app settings files. TOML's own parser catches malformed syntax, but not a missing required key, a wrong type, or a value outside an allowed set — a JSON Schema does, using the exact same rules you'd apply to a JSON or YAML version of the same config.

How it works

  1. Open Schema Validator and switch the data pane's format tab to TOML.
  2. Paste or upload your JSON Schema.
  3. Paste or upload your .toml file.
  4. Errors appear with an approximate line and a plain-English explanation.

Frequently asked questions

Can I validate a TOML config against a JSON Schema?

Yes — switch to the TOML tab, paste your schema, and paste or upload the file.

Exact line numbers?

Approximate, from the TOML parser's own error — JSON is the only format with exact line mapping.

Is my file uploaded anywhere?

No, everything runs client-side.

Need a different format? Schema Validator also supports JSON, YAML, XML, and CSV against the same schema.
