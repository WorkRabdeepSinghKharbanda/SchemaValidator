JSON Schema Tools

Everything around a JSON Schema besides validating against it — generate one, convert it to TypeScript, lint it, diff it, or fix broken JSON — free, in your browser.

Tools

  • OpenAPI Schema Validator — Import an OpenAPI or Swagger spec and validate payloads against any component schema.
  • JSON Schema Generator — Infer a draft schema from sample data.
  • Sample JSON Generator — Generate example data from a schema.
  • JSON Schema to TypeScript — Export a schema as a TypeScript interface.
  • JSON ⇄ YAML Converter — Convert data between JSON, YAML, TOML, XML, and CSV.
  • JSON Schema Linter — Best-practice hints for a schema.
  • Regex Tester — Test a schema's pattern keyword live.
  • Batch JSON Validator — Validate every record in an array against one schema.
  • JSON Schema Diff — Compare two versions of a schema.
  • JSON Repair — Auto-fix trailing commas, single quotes, unquoted keys, and some structural gaps.
  • JSON Schema Documentation Generator — Generate readable field docs from a schema.
